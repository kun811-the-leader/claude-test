# claude-test
Claude Code 테스트용 저장소

## 나만의 작업 도우미들

`.claude/skills/`에 아래 6개의 개인 업무용 스킬이 준비되어 있습니다. Claude Code에서 관련 요청을 하면 자동으로 트리거됩니다.

| 스킬 | 역할 | 비고 |
|---|---|---|
| `market-researcher` | 시장조사 담당자 | 시장/경쟁사/트렌드 리서치 리포트 작성 |
| `sales-assistant` | 영업담당자 | 아웃리치 메일, 제안서, 팔로우업 시퀀스 초안 작성 |
| `marketing-assistant` | 마케팅 담당자 | 콘텐츠 캘린더, 캠페인 기획, SNS/광고 카피 |
| `mail-checker` | 메일 확인 담당자 | Gmail 확인·요약·라벨 정리, 답장은 항상 초안(draft)만 |
| `file-organizer` | 파일 정리 담당자 | Google Drive 분류/이동/이름 정리는 자동 실행, 삭제는 항상 승인 후 실행 |
| `insight-sparring-partner` | 인사이트 토론자 | 아이디어를 비판적으로 검토해주는 소크라테스식 토론 파트너 |

각 스킬의 세부 동작 방식은 해당 폴더의 `SKILL.md`를 참고하세요.
